Michael Client Communications

Private client-reply monitoring

Personal-use desktop application · Read-only Gmail access

Michael Client Communications is a locally hosted tool used by the account owner to track replies to their video-editing outreach. It checks known Gmail conversations, organizes responses, and displays a notification in the owner's private Michael Command Center dashboard.

What the app does

  • Reads Gmail conversation metadata and message previews for outreach replies.
  • Separates genuine client responses from automatic replies and failed deliveries.
  • Stores a local, reviewable inbox and shows links back to the original Gmail messages.
  • Checks periodically without needing a ChatGPT conversation to remain open.

What it does not do

The app does not send email, delete messages, change Gmail labels, publish mailbox contents to this site, sell user data, or use Gmail data for advertising or general-purpose AI model training.

Local operation

The application runs on the owner's Windows computer. Message information is stored locally and Google credentials are encrypted for the current Windows user. This public website contains only the application's description and policies, and has no Gmail access.
