Privacy Policy

Effective October 10, 2026

Michael Client Communications is a personal-use Windows desktop application used by its owner to monitor responses to their video-editing outreach. The public website is informational and does not access Gmail or collect email messages.

Data the desktop application accesses

When the owner connects their Gmail account through Google's authorization screen, the application requests the Gmail API's read-only permission. It reads the owner's Gmail profile to verify the chosen account and retrieves messages and metadata in previously recorded outreach conversations. The information may include sender addresses, subject lines, message previews, message IDs, timestamps, and direct links to messages in Gmail.

Purpose and use of Google user data

The app uses Gmail data solely to display client replies in the owner's private, local inbox, distinguish automated responses and delivery failures, and show an unread notification in the owner's private Command Center. It does not send messages or change the mailbox. Gmail data is not used for advertising, sale, profiling, or general-purpose model training.

Storage and security

The inbox is stored in a local SQLite database on the owner's Windows PC. The offline OAuth credential is protected using Windows Data Protection API (DPAPI) under the owner's Windows account. Access to local files is restricted using Windows permissions. Neither Gmail credentials nor message contents are uploaded to this GitHub Pages website. Google account authorization is revoked through Google Account security settings; the owner can remove locally stored data from the PC.

Sharing and transfers

The app communicates directly with Google's OAuth and Gmail API endpoints over HTTPS. It does not transmit retrieved Gmail messages to other remote services and does not share Gmail data with advertisers, data brokers, or third parties. This website is hosted by GitHub Pages; normal website visitor requests may be handled and logged by GitHub under its own policies, but no Gmail account connection or messages pass through this website.

Retention and control

Locally collected messages and the review status remain until the owner deletes them. The owner can disconnect Google access through Google Account connections and delete the local application's data and encrypted credential to stop further access. The app monitors only while its local Windows service is running and authorized.

Google API Services User Data Policy

Use and transfer of information received from Google APIs will adhere to the Google API Services User Data Policy, including its Limited Use requirements. The app's read-only Gmail access is intended only for the features described here.
